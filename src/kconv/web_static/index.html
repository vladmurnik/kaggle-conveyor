ollama serve
ollama pull qwen2.5-coder:7b

Профиль 1–5 переопределяет стратегию и подбирает лимиты CPU/GPU.
Ресурсы: CPU / GPU / RAM опционально
Выберите профиль, чтобы переопределить CPU threads, RAM и VRAM.
Чем отличаются стратегии fast / standard / deep
fast 3 folds · 1 seed HPO off — быстрый baseline и первая проверка данных.
standard 5 folds · 2 seeds HPO off — стабильнее OOF без долгого поиска.
deep 5 folds · 3 seeds HPO on, 8 trials — дороже по времени и CPU/GPU.

Профиль 1–2 включает fast, 3–4 — standard, 5 — deep. Выбранный профиль имеет приоритет над стратегией.

10 / kaggle

          
Отправка submission

        

        проверка
      

      

        Вставьте API token из Kaggle Settings → API (или username/key из старого kaggle.json)
        один раз, укажите slug соревнования — дальше submission отправляется одной кнопкой.
        Секрет сохраняется только на этой машине и никогда не возвращается в браузер.
      

      

      

        
        
        

          Или старый kaggle.json: username + key
          

            
            
          

        

        
      

      

        
        
        
        Сначала завершите полный прогон.
      

      

      

        Где взять токен и что именно уходит на Kaggle
        

          
Откройте kaggle.com/settings → API → Generate New Token и скопируйте токен в поле выше. Для старого аккаунта можно раскрыть блок username/key и вставить данные из kaggle.json.

          
При нажатии «Отправить в Kaggle» kconv проверяет CSV (id + prediction, без пустых колонок) и вызывает официальный kaggle competitions submit. На Kaggle уходит только файл submission и сообщение; данные обучения остаются локально.

          
Если credentials уже заданы через KAGGLE_API_TOKEN, KAGGLE_USERNAME/KAGGLE_KEY или KAGGLE_CONFIG_DIR, переменные окружения имеют приоритет над файлом.
